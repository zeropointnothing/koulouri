# koulouri

a lightweight music player built for the user and powered by Python.

simple by design, letting you listen to your music without any distractions or unwanted features.

no AI bloat, no buggy or convoluted UI, and especially no ads. just you, _your_ music, and Koulouri. whether you're rocking out or simply having a chill break, Koulouri will play it.

# User Guide

this User Guide will teach you (hopefully) everything you need to know in order to use Koulouri.

**note, that this guide expects you to be running Koulouri in its TUI (`-c`, `--curses`) mode.**

## Important Terms

Koulouri uses some internal language to keep track of what's what. below is what some of those terms mean and how they're used/generated.

### TID

the TID (or Track ID) is a special string that acts as a unique identifier for a track.

---
TID's are generated during a library refresh and are assigned to each track that is successfully parsed. the value is generated by hashing a string of the format `<ARTIST><TITLE>`.

it is important to note that, because of the nature of hashing, modifying these values will result in the TID of that track to change, and any kData information related to it to no longer be valid.

## Important Files

Koulouri, as a music player, needs to store some persistent information. Below, you can find out what that information is and where you can find it.

### songcache

the most important file Koulouri creates!

can be found at `songcache.json`

---

finding track metadata is an expensive (in CPU terms) and lengthy process, as it has to manually parse _every_ file in your music folder to search them for the required data. while this is fine once, it would get really annoying really fast if Koulouri had to go through this process every time your started it up.

Koulouri solves this by storing the metadata it found in the 'songcache'. this is a special file that allows it to remember your library's metadata without having to parse it again manually.

in most cases, you will never have to touch this file. Koulouri uses it purely as a mirror to your library's metadata, so any changes you make in your library will automatically be reflected in the songcache on your next refresh.

this file _can_ be manually edited if you don't like how Koulouri scanned your library, but it is advised you do not do so, as modifying this file can cause the data within to be a format Koulouri doesn't expect and/or doesn't know how to handle. additionally, this file is very large and not formatted with indentation to save space, so mistakes are very easy to make.

***TLDR; if you would like to change a value here, change it in the track's metadata and not the songcache, then refresh. Koulouri will remember your changes afterwards!***

### kData

a special file that allows Koulouri to remember persistent user data!

can be found at `kdata.json`.

---
part of what makes a music player special is the ability to put your library into collections or groups. after all, once your library starts to grow large, scrolling through a 200-600+ track list can get a little tiresome.

Koulouri offers a solution to this via its kData system. the core of this system relies on Track ID's, or TID's (see [TID](#tid)) and their ability to remain persistent across library refreshes.

at the time of writing this, kData stores two sets of information: your favorites and your playlists. both of these store basic string info and rely on your songcache to identify songs by their TID.

although it's best to leave kData edits to Koulouri, this file _can_ be edited (with caution). note, that these changes must be done while Koulouri is closed, as it reads the file only once, then relies on a memory copy that will not update with the file until the next start.

in the case that your kData file is invalid, you can either delete it or ensure that it follows the following format:

```json
{
    "favorites": [

    ],
    "playlists": [
        {
            "name": "...",
            "tracks": []
        }
    ]
}
```

***TLDR: your kData file stores persistent information such as favorites and playlists. you can manually edit this file with caution, as it relies on songcache data to identify songs. if done, ensure Koulouri is not running as it will not update until the next start.***

## Views

Koulouri splits its main functions into different 'views'. Each view will allow you to interface with your music differently, though keybinds are generally the same across them. you'll know what view you're currently in by looking at the title bar. it's the third section, and defaults to the 'track' view!

### tracks

`t`

the tracks view is the main view for Koulouri. It displays all of your music (that Koulouri is aware of, see REFRESH) in a list that can be scrolled and selected from.

### albums

`a`

the albums view is a special filter that will show only the names of your albums. from here, you can either add specific tracks or the entire album.

### queue

`q`

the queue view displays all the songs in your queue. songs before the playing indicator "`~`" have already been played, while songs after will be played next.

### enter

`e`

the "enter" view, or filter view is a special mode for the tracks view that will show only a specifc set of songs.

while in this view, the `[E]` symbol, followed by the title of the filter will be dislpayed. you can deactivate this view at any time by pressing `e` with no selection.

activating the view on an album will filter out all songs except for those in the album. likewise, activating the view on a playlist will filter out all songs not in the playlist.

if activated from a playlist, the `r` key will delete the selected track from the currently viewed playlist.

### lyrics

`l`

if any can be found, Koulouri will display the lyrics of the currently playing song when this view is active.

Koulouri will search only for a `.lrc` file with a matching name for lyrics. so, for example, if your song's filename was `STARSET - Vessels - 12 Unbecoming.flac`, the lyric file would need to be named `STARSET - Vessels - 12 Unbecoming.lrc`.

Koulouri expects a specific format of lyric file to be present. this format requires each line to have a start time and no end time, like so:
```
[id: psjfgylu]
[ar: STARSET]
[al: Vessels]
[ti: Unbecoming]
[length: 04:10]
[00:00.36]I lost myself into the night
[00:05.62]And I flew higher
[00:09.08]Than I had ever, but I still felt small
[00:14.23]I clipped my wings and fell from flight
```
note, that only the timed lines with the format `[--:--.--]text...` (`[minutes:seconds.miliseconds]lyric`) are considered and the rest are ignored.

by default, Koulouri will automatically scroll with the lyrics as they play, showing the current lyric by placing a "`~`" symbol in front. you can override this scrolling behavior by scrolling yourself and renable it by pressing `l` again.

### favorites

`f`

the favorites view is a special filter that will only display songs you've marked as a "favorite".

it is one of the few views that relies on the [kData](#kdata) system.

### collections

`C`

view existing playlists, which can be added to the queue in their entirety, or [entered](#enter) to add specific tracks.

### collection wizard

`c`

a very special view that allows for the creation of playlists.

will display a list of all currently created playlists and a text input box.

if the currently selected track is already present in the playlist, the playlist's name will be green.

will automatically focus a playlist as its name is inputted if it can be found. pressing `<TAB>` will autofill its name into the textbox.

if a playlist with the name stored in the textbox does not exist, it will be created and the track will be added to it.

## How-To

want to know how to do something? check here!

### adding/removing tracks

to add a track to your queue, open your [tracks](#tracks) view and type in the index of the track you wish to add. then, press the Enter key!

to remove a track from your queue, open your [queue](#queue) view, type in the index of the track you wish to remove, then press the Enter key!

### adding an album

to add an entire album, open your [album](#albums) view, type in the index of the album you want to add, then press the Enter key!

### adding/removing favorites

to toggle a track as a favorite, simply press the `*` key. if you have a track selected, it will toggle that one. otherwise, it will toggle the currently playing track.

### inserting tracks, albums, or playlists

by default, Koulouri will append the new tracks to the very end of your queue. if you would like Koulouri to "play next", press the `i` key. this will enable Insert Mode, indicated by the `[I]` symbol in front of the user input. now, when you attempt to add new tracks, they will be placed right after the currently playing track.

to disable Insert Mode, press `i` one more time.

### "opening" playlists/albums

to view inside a playlist or album, use the [enter view](#enter).

### adding tracks to playlists

to add a track to an existing or new playlist, first open the [Collection Wizard](#collection-wizard) with either a track playing or a track selected. then, type in either the name of an existing playlist (you can press `<TAB>` to autocomplete it for you!) or the name of a new one and press enter.

### removing tracks from playlists

you can remove a track from a playlist in two ways.

A:
  open the [Collection Wizard](#collection-wizard), locate the playlist you wish to modify, then press enter. the playlist's name should no longer be green.

B: open the [collections](#collections) view, then [enter](#enter) the playlist you wish to modify. finally, select the track you wish to remove by typing in its index and press the `r` key.

### viewing playlists

to view all of your existing playlists, press the `C` key (note the capital!).

### deleting playlists

to delete a playlist, press the `r` key while not currently viewing one via the [enter](#enter) view.

ensure the name of the playlist you wish to delete is red, then type in its name (you can use the `<TAB>` key to autocomplete this!) to confirm and press enter.

### seeking

due to the nature of PyAudio, Koulouri natively supports seeking! to do so, simply press the Left or Right arrow keys. it is recommended that you do this while paused, as rapidly jumping around 5 seconds intervals is not a very pleasant audible experience.

### pausing

to pause the current playback, press the Spacebar key. the current state is shown in front of the playback bar as either playing (`>`) or paused (`#`).

note, that Koulouri will not load the next song if it is currently paused.

### skipping/restarting tracks

to skip the currently playing track, press the `n` key. this will immediately end playback of the current track and Koulouri will then play the next one in the queue.

to restart a track, press the `p` key. note, that this key has a special behavior: if the current track has been playing for longer than 5 seconds, it will restart the track. if it has been playing for less than 5 seconds, it will instead jump back to the previous track in the queue.

### scrolling

to scroll in any view that supports it, press either the Up or Down arrow keys. on most systems and terminals, scrolling with your mouse wheel is also supported.

### adjusting volume

to adjust Koulouri's volume, press either the `-` or `+` keys. Koulouri's current volume is indicated by the percentage in the center of the title bar.
